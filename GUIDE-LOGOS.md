2. Rechercher : "[marque] logo png transparent"
3. Filtres :

## 📂 Organisation des Fichiers

Une fois téléchargés, renommer les fichiers comme suit :

```
images/logos/
├── daikin.png          (ou .jpg)
├── mitsubishi.png
├── bosch.png
├── atlantic.png
├── airwell.png
├── fujitsu.png
└── toshiba.png
```

### Commandes pour créer le dossier

```bash
mkdir images/logos
```

## ✅ Critères de Qualité des Logos

### Format Recommandé
- **PNG avec fond transparent** (idéal)
- **OU** PNG/JPG avec fond blanc

### Dimensions
- **Largeur minimum** : 300px
- **Hauteur minimum** : 100px
- **Ratio** : Horizontal de préférence

### Qualité
- Image nette (pas floue)
- Bonne résolution
- Couleurs originales de la marque

## 🚀 Instructions Après Téléchargement

### Étape 1 : Placer les Logos
Placez tous les logos téléchargés dans le dossier `images/logos/`

### Étape 2 : Vérifier les Noms
Assurez-vous que les fichiers sont nommés exactement :
- `daikin.png` (ou .jpg)
- `mitsubishi.png`
- `bosch.png`
- etc.

### Étape 3 : Le Site se Mettra à Jour Automatiquement
Le code HTML est déjà prêt pour afficher les logos dès que vous les placez dans le dossier !

## 💡 Conseils

### Si le Logo a un Fond Coloré
Certains logos ont un fond blanc ou coloré. Ce n'est pas grave :
- Le site les affichera quand même
- Ils auront un fond blanc dans la section partenaires

### Si Vous ne Trouvez pas un Logo
Ne vous inquiétez pas :
- Le site affichera le nom de la marque en texte (comme actuellement)
- Vous pourrez ajouter le logo plus tard

### Droits d'Utilisation
En tant que partenaire/revendeur officiel de ces marques :
- ✅ Vous avez le droit d'utiliser leurs logos
- ✅ C'est normal et attendu
- ✅ Ça renforce votre crédibilité

## 🎨 Alternative : Demander les Logos Directement

## ❓ Questions Fréquentes

### Faut-il tous les logos en même temps ?
Non ! Vous pouvez commencer avec Daikin et Mitsubishi (les plus importants) et ajouter les autres progressivement.

### Quel format préférer : PNG ou JPG ?
**PNG** est préférable, surtout avec fond transparent. Mais JPG fonctionne aussi.

### Les logos doivent-ils être de la même taille ?
Non, le site ajustera automatiquement la taille. Mais une taille similaire est plus esthétique.

### Que faire si le logo est trop petit ?
Cherchez "logo haute résolution" ou "logo HD" dans votre recherche Google.

## 🎁 Bonus : Logos Déjà Préparés

Si vous avez des logos dans vos documents (contrats, présentations PowerPoint, etc.) :
1. Ouvrez le document
2. Clic droit sur le logo > "Enregistrer l'image sous..."
3. Sauvegardez au format PNG
4. Placez dans `images/logos/`
